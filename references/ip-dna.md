# IP DNA — Re7

## Character Definition

Re7 是一个约小学年纪的 Q 版小男孩，作为创作者分身出现在文章配图里。他不是角落装饰，而是亲自完成筛选、连接、搬运、操作和指向等关键动作的概念参与者。

## Appearance

约四头身 chibi 男孩：墨黑略乱短发、发间多缕天蓝、蜜琥珀圆眼带虹膜瞳孔与双高光、淡腮红、轻轻带一点得意的微笑。藏青连帽衫，青色内衬，左胸青色描边的白色 7 徽章，炭灰短裤，藏青袜，白鞋带海军条。

## Body Proportion

约 4 头身，头大、肩窄、四肢短圆，低重心。全身必须从头到脚完整可见；手只有两只，每只都能从肩膀连续追溯到手指。

## Face

圆脸、大圆眼、蜜琥珀色虹膜、深色瞳孔、两处白色高光、细上睫毛、淡腮红、小小闭合式微笑。不是空眼白，不是半眯眼默认脸。

## Hair / Head Feature

墨黑略乱短发，刘海分开眼睛。发间固定有多缕天蓝色挑染（刘海与两侧都可见），不可收成只剩一缕，也不可改成粉发或其他发色。

## Clothing

固定套装：宽松藏青色连帽衫（青色内衬）+ 炭灰短裤 + 藏青袜 + 白色运动鞋（侧面海军条）。左胸固定青色描边的白色 7 徽章，这是唯一徽章。场景道具（平板、箱子、纸条）可以拿，但不能替换这套身份服装，也不能加回胶片针或其他胸针。

## Colors

主色藏青与天蓝；辅色炭灰、蜜琥珀（虹膜）、白（鞋、7 字）。7 为青色描边白色数字。整体是日式赛璐璐色块，不用霓虹、不用暖米色开衫、不用淡紫 7。

## Personality

好奇、会动手、讲得清、有一点点得意。默认轻微笑；思考时托腮，做成时可以更开心或向前指，但不变成夸张吉祥物表情。

## Signature Features

- 墨黑短发里的多缕天蓝挑染
- 蜜琥珀虹膜的大圆眼
- 藏青连帽衫 + 青色内衬
- 左胸青色描边白色 7
- 炭灰短裤 + 白鞋海军条

## Common Actions

- 指向关键对象
- 双手或单手拿起、搬运物体
- 坐下思考或托腮
- 走路走向结果
- 操作平板或简单工具
- 把对象分类、连接、推开或放进容器

## Role in Illustrations

Re7 必须亲自触发概念的状态变化：筛选、搭建、连接、转化、归档或推动。如果删掉 Re7 后隐喻仍然完整，构图失败，必须让关键变化由他的动作完成。

The character must participate in the concept's indispensable action. If removing the character leaves the visual metaphor intact, redesign the composition.

## Must Preserve

- 墨黑短发 + 多缕天蓝挑染
- 大圆眼、蜜琥珀虹膜、瞳孔、双高光
- 藏青连帽衫 + 青色内衬
- 左胸青色描边白色 7（唯一徽章）
- 炭灰短裤 + 藏青袜 + 白鞋海军条
- 约 4 头身与轻微笑
- 只有一个 Re7，最多两只手

## Forbidden Changes

- 改发色或拿掉天蓝挑染
- 空眼白或更换虹膜颜色
- 换成其他套装或把白鞋换成乐福鞋
- 拿掉或改写 7，或把 7 改成淡紫描边
- 加回胶片齿孔针、第二枚徽章或胸针
- 变成少年、成人或第二个角色
- 多手、多臂、断臂、融合肢体
- 复刻旧版 Re7：亚麻帘幕刘海、左侧小杏、奶油开衫、sage 短袖、棕色乐福鞋
- 复刻粉发、绿瞳、黑色校服裙、猫耳发夹
