# IP DNA — Re7

## Character Definition

Re7 是一个约小学年纪的 Q 版小男孩，作为创作者分身出现在文章配图里。他不是角落装饰，而是亲自完成筛选、连接、搬运、操作和指向等关键动作的概念参与者。

## Appearance

三头身 chibi 小男孩：亚麻短发、帘幕刘海、左侧一颗小杏、暖棕圆眼带虹膜瞳孔与高光、淡腮红、轻轻微笑。奶油罗纹开衫敞穿，内搭 sage 短袖，卡其短裤，奶油袜，棕色乐福鞋，开衫左胸有淡紫描边的 7 徽章。

## Body Proportion

约 3 头身，头大、肩窄、四肢短圆，低重心。全身必须从头到脚完整可见；手只有两只，每只都能从肩膀连续追溯到手指。

## Face

圆脸、大圆眼、暖棕色虹膜、深色瞳孔、白色高光、细上睫毛、淡腮红、小小闭合式微笑。不是空眼白，不是半眯眼默认脸。

## Hair / Head Feature

亚麻浅棕短发，柔软帘幕刘海分开眼睛，发丝略乱。左侧头发里固定一颗小杏（带短叶），不可换成花或其他头饰。

## Clothing

固定套装：奶油色罗纹针织开衫（敞穿）+ sage 绿短袖 T 恤 + 卡其/橄榄短裤 + 奶油中筒袜 + 棕色乐福鞋。开衫左胸固定淡紫描边 7 徽章。场景道具（平板、箱子、纸条）可以拿，但不能替换这套身份服装。

## Colors

主色奶油米白与 sage 绿；辅色卡其橄榄、暖棕（鞋、虹膜、头发）、暖杏（小杏）；点缀淡紫 7。整体低饱和暖纸色，不用霓虹、正红、大块纯黄。

## Personality

好奇、会动手、讲得清、有一点点得意。默认轻微笑；思考时托腮，做成时可以更开心，但不变成夸张吉祥物表情。

## Signature Features

- 帘幕刘海的亚麻短发
- 左侧小杏
- 暖棕虹膜的大圆眼
- 奶油罗纹开衫 + sage 短袖
- 开衫上的 7 徽章
- 棕色乐福鞋

## Common Actions

- 指向关键对象
- 双手或单手拿起、搬运物体
- 坐下思考或托腮
- 走路走向结果
- 操作平板或简单工具
- 把对象分类、连接、推开或放进容器

## Role in Illustrations

Re7 必须亲自触发概念的状态变化：筛选、搭建、连接、转化、归档或推动。如果删掉 Re7 后隐喻仍然完整，构图失败，必须让关键变化由他的动作完成。

The character must participate in the concept's indispensable action. If removing the character leaves the visual metaphor intact, redesign the composition.

## Must Preserve

- 亚麻短发 + 帘幕刘海
- 左侧小杏
- 大圆眼、暖棕虹膜、瞳孔、高光
- 奶油罗纹开衫 + sage 短袖 + 卡其短裤
- 奶油袜 + 棕色乐福鞋
- 开衫上的 7 徽章
- 约 3 头身与轻微笑
- 只有一个 Re7，最多两只手

## Forbidden Changes

- 改发型发色或拿掉小杏
- 空眼白或更换虹膜颜色
- 换成其他套装或把乐福鞋换成运动鞋
- 拿掉或改写 7 徽章
- 变成少年、成人或第二个角色
- 多手、多臂、断臂、融合肢体
- 复刻 XILO 的白花头饰、空白眼和固定白衣草绿短裤
