# Style DNA

## Canvas / Aspect Ratio

正文配图默认 16:9 横图；角色设定参考为 1:1 全身。

## Background

暖米色纸底，干净、浅、可有极淡的桌面或简单道具色块，不画复杂透视房间，不出现黑色边框截图感。

## Line Style

细而稳的灰绿色/暖灰色墨线，圆角收笔，线宽统一，不漫画网点，不粗黑勾线。

## Rendering

平涂绘本上色，少量软阴影与淡腮红，色块干净，不厚涂、不 3D、不赛博、不写实。

## Color Palette

暖米、sage、卡其、暖棕、暖杏、淡紫 7；全局低饱和。文字批注用 sage 或暖棕，不用荧光色。

## Spacing

大留白，角色和关键物件居中或按阅读动线放置，四周呼吸感强，不铺满信息图表。

## Composition Density

一图一意，2-5 个主要物件。连续配图至少换两种结构或动作，避免反复左右流程图。

## Typography / Annotation

默认 2-6 个中文短批注，每项 2-8 个汉字，总量尽量不超过 28 字。手写感或细圆体，贴近对应对象、动作或结果，可配小箭头或圈点。禁止顶部巨大标题、长句、PPT 标签框。所有文字必须在 prompt 里逐字写出，模型不得自由补词。用户明确要求无字时才省略。

## Texture

轻纸纹、轻微颗粒，保持印刷绘本质感。

## Lighting

均匀柔光，没有戏剧性聚光，没有硬投影。

## Visual Mood

温暖、清楚、好脾气的讲解绘本，像工作室里的纸上演示，而不是海报、表情包或潮牌大片。

## Must

- 暖米色纸底与细灰绿线
- 平涂绘本、低饱和
- Re7 全身可辨且参与关键动作
- 中文短批注逐字指定并贴近对象
- 16:9 正文图留出呼吸空间

## Avoid

- 霓虹赛博、厚涂油画、3D 黏土、写实照片
- 海报大标题和 PPT 色块标签
- 复杂 UI 截图、水印、第三方 logo
- 多角色、观众席、装饰用小人
- 把 Re7 缩在角落当吉祥物
