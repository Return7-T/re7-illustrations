# Style DNA

## Canvas / Aspect Ratio

正文配图默认 16:9 横图；角色设定参考为 1:1 全身。

## Background

干净浅白或极浅灰底，可有简单色块道具（箱子、平板、纸、小方台），不画复杂透视房间，不出现黑色边框截图感，不使用暖米色纸纹底。

## Line Style

干净等宽的深色勾线，中等线宽，圆角收笔，线宽统一。日式 TV 动画赛璐璐线，不漫画网点，不粗黑海报勾线，不灰绿绘本线。

## Rendering

赛璐璐平涂，一块简单阴影，色块干净，淡腮红。不厚涂、不 3D、不赛博、不写实、不平涂绘本纸纹。

## Color Palette

藏青、天蓝、炭灰、蜜琥珀、白、浅肤色；7 用青色描边白色数字。文字批注用藏青或天蓝，不用荧光色，不用 sage / 暖杏 / 淡紫作为主色。

## Spacing

大留白，角色和关键物件居中或按阅读动线放置，四周呼吸感强，不铺满信息图表。

## Composition Density

一图一意，2-5 个主要物件。连续配图至少换两种结构或动作，避免反复左右流程图。

## Typography / Annotation

默认 2-6 个中文短批注，每项 2-8 个汉字，总量尽量不超过 28 字。干净圆体或细等线，贴近对应对象、动作或结果，可配小箭头或圈点。禁止顶部巨大标题、长句、PPT 标签框。所有文字必须在 prompt 里逐字写出，模型不得自由补词。用户明确要求无字时才省略。

## Texture

数字赛璐璐，表面干净，没有纸纹、颗粒或印刷噪点。

## Lighting

均匀柔光，一块简单赛璐璐阴影，没有戏剧性聚光，没有硬写实投影。

## Visual Mood

清楚、好脾气、带一点得意的讲解动画，像日式 TV 赛璐璐角色在演示概念，而不是海报、表情包、潮牌大片或暖纸绘本。

## Must

- 浅白底与干净等宽勾线
- 赛璐璐平涂、一块阴影
- Re7 全身可辨且参与关键动作
- 中文短批注逐字指定并贴近对象
- 16:9 正文图留出呼吸空间

## Avoid

- 暖米色纸纹绘本、灰绿墨线、厚涂油画、3D 黏土、写实照片、霓虹赛博
- 海报大标题和 PPT 色块标签
- 复杂 UI 截图、水印、第三方 logo
- 多角色、观众席、装饰用小人
- 把 Re7 缩在角落当吉祥物
- 旧版 Re7 的奶油开衫与小杏造型
